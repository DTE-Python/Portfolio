# Racing Horse Data Collection
Commissioned in November 2024.
## Purpose
To scrape bloodhorse.com for information about racing horses and output the data to a CSV file.

## Procedure
- Step 1: Access Bloodhorse and store links to every horse's page.
- Step 2: Bloodhorse gets information from Equineline. From the Bloodhorse page, get the Equineline link.
- Step 3: Parse the Equineline plaintext and store the data into an SQLite database.

## Lessons
Through this project I was able to explore SQLite database management, HTTP requests and headers, multithreaded processing, and project management skills.

#### Reception
The project was considered a success by the client, and a fair price was agreed upon.
