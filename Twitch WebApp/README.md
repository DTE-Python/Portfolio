# Twitch WebApp
The exact time I started working on this I can't recall. 
## Purpose
To communicate with the Twitch API, receive webhooks, and ultimately provide a visual display for custom Twitch channel point redemptions.

## Lessons
I was able to go in-depth with OAuth and Twitch's API. I learned a lot about HTTP requests, which wound up laying the groundwork in my mind for <a href="https://github.com/DTE-Python/Portfolio/tree/main/Racing%20Horse%20Data%20Collection%20(Commision)">another project</a>, but ultimately I discovered that one of my goals, which was to procedurally edit an animation depending on a few key factors, wasn't going to be seamlessly provided using JavaScript alone.

At another time, when I was ready to continue the project, I discovered <a href="https://streamer.bot/">streamer.bot</a>, which was a more impressive version of the concept I was going for, so the real lesson is to do a little more research for existing tools!
